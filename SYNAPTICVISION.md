# Synaptic Vision

> IKS' OET (ontology, epistemology, teleology) must question hitherto innocuous paradigms- Sacred, God, Technology, Reality, Disruption, Progress, etc.- in native code. For us to reconnect to our civilizational consciousness, we must be able to deploy and derive from a native-rooted framework. Such a framework would, in turn, help reconnect synaptic nerves to the civilizational consciousness.

Original ideas unpacked in [Part 1](https://www.bodharesearch.in/blog/synaptic-reconnection-1) and [Part 2](https://www.bodharesearch.in/blog/synaptic-reconnection-2).

The technical objective is to build a discovery and journeying platform. Think of a Sanskrit word. Any word. Look it up in the synaptic reconnector.

1. See it etymology, understand the root dhatu, explore the semantic web that blooms through related words.
2. See where the word occurs across Sanskrit literature. 
3. Find meaningful semantic interconnections via dhatupatha, text concordances, and the amarkosha.
4. Interactive "return" map porting the discoveries via English language syncordances.
=> Understand what that word actually means to the Hindu mind.
